Cookie Run combi codes

A combi name holds 10 characters - enough to carry the run's goal, whether it plays itself, the episode, boosts, random boost, cookie power+ selections, and starting action. Put a loadout section in front and the same code carries your cookie, relay, pet, and treasures too. Build one below, or edit the code itself and watch the controls follow.

      Special episodes

      Special Episodes 1 and 2 take a cookie, a pet and treasures - no relay, boosts, random boost or cookie power+, so slots 5-9 read 0. Special Episode 2 spends slots 5-7 on the tower floor instead: 001-100, or 000 for any floor. The Special Exp Episode takes a cookie and a pet only.

      The loadout section

      Everything left of the dash. Groups always read in the order C R P T, and a group you did not pick is simply absent.

      Group Field Characters
      1 Loadout version Always 1, and separate from the name's version
      C Cookie 2 characters
      R Relay 2 characters, from the same list as the cookie
      P Pet 2 characters
      T Treasures U any order or O exact order, then up to 3 slots of 3 characters each, separated by .. Alternatives within a slot are joined by _

      Auto vs semi-auto

      An auto build is semi-auto when any of these is true: Fast Start is on (slot 5), a random boost is selected (slot 6), there is a jump action (slot 10), or the loadout carries a relay cookie (the R group). A relay is swapped in by hand, so a run carrying one never plays itself through. Slot 2 stores A or H so the name reads plainly, but those four are the authority - building a code always rewrites slot 2 to match them.
